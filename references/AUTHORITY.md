# 可信度分级与溯源规则

本目录 84 篇上游文档来自 `dsh-hoi4-modding`，是**一位作者在开发自己那个 mod 的过程中写的笔记**，不是社区规范，也不是官方文档。

所以在用它之前，先分清哪部分能信、信到什么程度。

## 实测分布

对 88 个文件全量统计（`2026-11-06`）：

| 指标 | 数量 |
|---|---|
| 引用了游戏内路径（`common/…`、`documentation/…`）的篇数 | 81 / 88 |
| 带行号引用的篇数 | 33 / 88 |
| 用「本机实测」作为证据的篇数 | 23 / 88 |
| 使用 `HHO_` 前缀（作者自己 mod 的命名）的处数 | 452，分布在 31 篇 |
| 引用 `.tmp/`、`game-survey.md` 等未随包产物 | 18 处 / 13 篇 |

结论一句话：**结构和路径部分是硬的，内容示例部分是软的。**

## 三级可信度

### A 级 —— 可当场复核

特征：给出 `<GAME_DIR>/common/xxx/yyy.txt:123` 这类坐标，能直接打开看。

适用：`00_start/`（目录结构、加载顺序）、`01_script/`（scope/effect/trigger 语法）、`04_world/`（地图文件格式）、`05_presentation/` 的文件格式部分。

用法：**可以直接照做**，但遇到关键判断仍应打开原文件确认——文档可能滞后于你装的版本。

### B 级 —— 作者单机实测，你无法复核

特征：写「本机实测」「实测于 1.19.3」，但没给可查的坐标或给了 `.tmp/` 里的私有文件。

适用：`03_military/`（战斗宽度、装备层级）、`04_world/supply.md`、`05_presentation/fonts-cjk.md` 的字体名单、`06_workflow/performance.md`。

用法：**当线索，不当结论**。要用于交付前，按它给的方法在自己的游戏里复现一次。

### C 级 —— 作者项目经验，不是通用做法

特征：大量 `HHO_` 前缀、`90_case-studies/` 全篇、`AGENTS.md`、`.tmp/audit/`。

适用：`90_case-studies/`（5 篇）、`02_content/` 里那些用 `HHO_` 举例的段落（focus 36 处、characters 36 处、intelligence 36 处、history 35 处最集中）。

用法：**只当"别人是这么做过"的参考，绝不能当规范**。作者自己的库也在 `_index.md` 里写了「案例是实战记录，不是默认做法」。

## 溯源规则（写笔记、写技能时强制）

任何一条要留下来的知识，必须带下面三种坐标之一，否则就是没写完：

| 类型 | 写法 | 例 |
|---|---|---|
| 游戏文件 | `<相对路径>:<行号>` | `common/decisions/_documentation.md:12` |
| 官方文档 | `documentation/<文件名>:<行号>` | `documentation/effects_documentation.md:7888` |
| 外部来源 | 链接 + 抓取日期 | `https://hoi4.paradoxwikis.com/Effect`（2026-11-06） |

**不接受**的证据形式：

- 「实测」「本机验证」「一般情况下」——没有坐标，别人无法复核
- 「社区常用」「大家都知道」——没有出处
- 作者某个 mod 里的写法——那是 C 级

## 与本插件其他知识源的关系

权威性从高到低：

```
游戏自带 documentation/*.md            字段级权威，553 effect + 596 trigger 可查
  ↓
common/**/_documentation.md            31 处域级文档
  ↓
原版实例文件                            没有官方文档的域只能靠它
  ↓
本目录 A 级                             二手整理，坐标可查
  ↓
本目录 B 级 / 官方 wiki / 稳定发布 mod    线索
  ↓
本目录 C 级                             案例，非规范
```

前四层在本机就能查（`kiant_hoi4_kb_build` 已索引），第五层之后要靠人判断。

## 使用建议

1. **先查原版，再查这里。** 字段名、scope、effect 是否存在，`kiant_hoi4_kb_search "<名字>" kind=md` 一条命令就有答案，比翻文档快。
2. **看到 `HHO_` 就换成自己的前缀。** 那是作者的 mod 叫法，不是约定。
3. **B 级结论要复现。** 尤其军事数值和字体名单——作者的环境和你不同。
4. **C 级只读思路。** 案例区的价值是"这个问题可以这样绕过去"，不是"你就该这么写"。
