# SOL-002 科技卡图标导入

## 它想解决什么

把照片或矢量图批量做成 HOI4 科技卡图标。这件事看着简单，实际有三个坑：

1. **几何不对**：科技卡是 183×84，Icon 控件中心在 x=74。所以图标内容必须**左留 20、右留 4**，否则看起来偏左
2. **背景不干净**：来源可能是白底照片、透明 PNG、或是"透明被截图成 8px 棋盘格"
3. **白涂装**：白色涂装的车辆/装备，按白色阈值抠图会把主体一起抠掉

对应错题本：`EB-005`。

## 思路

上游 `tech_icon_import.py` 的输入分三类处理：

| 输入类型 | 处理方式 |
|---|---|
| 透明 PNG（最佳） | 直接用 alpha 通道 |
| 白底照片 | 按白色阈值抠 |
| 8px 棋盘格（白 + 灰） | **不能**用白色阈值，要先识别 8px 周期的格纹 |

输出用 `173×77` DDS，并按上述安全区几何定位。

还有个细节：**别名表消歧**。同型号装备可能有多个名称（虎式 E 型 / Tiger E / Pz.Kpfw. VI），需要一张映射表决定输出文件名，否则批量处理会产出重名或乱名。

## 为什么没被采用

同 SOL-001：涉及图像处理，需要 Pillow 或 numpy，与本插件"零依赖"定位冲突。而且这是个偏美术流水线的活，不是日常 mod 开发必备。

## 如果要用，怎么验证

1. 读上游源码确认依赖：

```bash
grep -n "^import\|^from" <上游路径>/tech_icon_import.py
```

2. 用三张测试图各跑一次：透明 PNG、白底照片、棋盘格截图
3. 把输出的 DDS 放进 mod，游戏内看科技卡图标

验证标准：图标不变形、内容不偏左、背景干净、白涂装主体保留完整。

## 备注

上游的真实使用记录在 `references/90_case-studies/icon-pipeline-tech-card.md`（本插件已收录）。那篇讲了完整的批量流程，即使不用这个工具，**去背策略和踩坑记录本身也有参考价值**。

一个可复用的判断：**"白底"和"白涂装"要用不同的抠图策略**，这个区分不理解清楚，批量脚本必然出错。
